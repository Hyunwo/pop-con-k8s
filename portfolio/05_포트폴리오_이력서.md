# PopCon 포트폴리오/이력서 정리

## 프로젝트 한 줄 요약
팝업스토어 이벤트 오픈 순간 22,500명 동시 접속을 목표로 한 MSA 기반 티켓팅 서비스의 클라우드 인프라 설계 및 구축

## 담당 역할
- Istio 서비스 메시 설계 및 구축
- 클라우드 인프라 운영 (EKS, Karpenter, ArgoCD)
- GitOps 기반 배포 관리

## 기술 스택
- **컨테이너 오케스트레이션**: Kubernetes (EKS 1.35)
- **서비스 메시**: Istio (VirtualService, DestinationRule, PeerAuthentication, AuthorizationPolicy)
- **노드 자동화**: Karpenter (Spot + On-demand)
- **CD**: ArgoCD (GitOps)
- **IaC**: Terraform
- **모니터링**: Prometheus, Grafana, Jaeger, Kiali
- **클라우드**: AWS (EKS, RDS, ElastiCache, ECR, ALB, Parameter Store, IRSA)
- **보안**: mTLS STRICT, Cloudflare

## 주요 성과

### 인프라 안정성
- Spot 인스턴스 중단 시 좀비 NodeClaim 문제 근본 해결
  - terminationGracePeriod 설정 + Spot 풀 고갈 인스턴스 타입 제거
- startupProbe 타임아웃으로 인한 반복 재시작 문제 해결
  - 로그 분석으로 앱 기동 시간과 probe 설정 간 불일치 파악

### 서비스 메시 (Istio)
- mTLS STRICT 모드로 내부 서비스 간 통신 전 구간 암호화
- 서비스별 Circuit Breaker 설정으로 장애 전파 차단
- AuthorizationPolicy로 서비스 간 접근 제어
- Envoy 사이드카로 코드 수정 없이 메트릭/트레이스 자동 수집

### 부하테스트 결과
- Scenario 1 (탐색): 350만 건 중 성공률 99.15%, median 41ms
- Scenario 2 (경매): 안정 구간 50~75 VU에서 bid 100%, 초과 판매 0건
- Scenario 3 (드로우): draw_entry 100%, VQA 100%, VU 2.5배 증가에도 안정

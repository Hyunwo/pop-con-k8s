# PopCon 프로젝트 개요

## 프로젝트 목적
팝업스토어 이벤트 오픈 순간 수만 명이 동시 접속하는 상황에서 서비스가 안정적으로 동작하도록 클라우드 인프라를 설계하고 구축.

## 핵심 문제
1. 트래픽 집중: 평소 한산 → 이벤트 오픈 순간 폭발적 트래픽
2. 정합성: 동시 입찰/응모 시 초과 판매 방지
3. 보안: 매크로 차단, 내부 서비스 간 통신 보호

## 주요 SLO
- 목표 CCU: 22,500명 (15,000석 × 1.5배)
- P95 응답시간: 500ms 이하
- 에러율: 1% 미만
- 대기열 이탈률: 5% 미만

## 서비스 구성 (8개 마이크로서비스)
- backend-user: 사용자 서비스
- backend-auth: 인증 서비스
- backend-popup: 팝업 서비스
- backend-auction: 경매 서비스
- backend-draw: 드로우(추첨) 서비스
- backend-queue: 대기열 서비스
- backend-queue-worker: 대기열 워커
- backend-anti-macro: 매크로 탐지 서비스
- frontend: 프론트엔드

## 네임스페이스
- popcon-prod: 서비스 운영
